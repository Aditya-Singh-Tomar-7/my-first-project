2. कार्यविधि (Procedure)

इस प्रोग्राम में हम यूज़र (उपयोगकर्ता) से दो नंबर मांगेंगे और उन दोनों का जोड़ (Addition) करके स्क्रीन पर दिखाएंगे।

  1. Python IDLE खोलें और File ➔ New File दबाकर नई स्क्रिप्ट खोलें।
  2. यूज़र से इनपुट लेने के लिए input() फंक्शन का प्रयोग होता है। चूंकि इनपुट टेक्स्ट रूप में आता है, उसे नंबर (Integer) में बदलने के लिए int() का प्रयोग करेंगे।
  3. निम्नलिखित कोड टाइप करें:
    # यूज़र से पहला नंबर लेना
    a = int(input("पहला नंबर दर्ज करें: "))

    # यूज़र से दूसरा नंबर लेना
    b = int(input("दूसरा नंबर दर्ज करें: "))

    # दोनों को जोड़ना
    total = a + b

    # आउटपुट प्रिंट करना
    print("दोनों नंबरों का जोड़ है:", total)
  4. कोड को calculator.py नाम से सेव (Ctrl + S) करें।
  5. प्रोग्राम को रन करने के लिए कीबोर्ड से F5 दबाएं।
  6. अब Python Shell आपसे नंबर मांगेगा। कीबोर्ड से नंबर टाइप करके Enter दबाएं।

3. परिणाम (Result)

Python में input() तथा int() फंक्शन्स का सफलतापूर्वक उपयोग करके यूज़र से रन-टाइम (Run-time) पर नंबर लिए गए और उनका गणितीय जोड़ (Addition) किया गया।
