प्रयोग संख्या - 19 (Practical No. 19)

उद्देश्य: HTML और CSS का उपयोग करके साधारण वेब पेज (Web Page) बनाना।

1. आवश्यक उपकरण एवं सॉफ्टवेयर

क्र.सं.सॉफ्टवेयर / उपकरणविवरण
1Text EditorVS Code, Notepad++ या Notepad
2Web BrowserChrome या Edge (आउटपुट देखने के लिए)

2. कार्यविधि (Procedure)

A. HTML का मूल ढांचा (Skeleton) तैयार करना

  1. अपना टेक्स्ट एडिटर खोलें (जैसे VS Code) और एक नई फाइल बनाएं।
  2. उसमें HTML का बेसिक कोड लिखें जिसमें <html>, <head>, और <body> टैग्स हों।
  3. इस फाइल को index.html नाम से सेव करें।

B. HTML टैग्स और CSS स्टाइलिंग जोड़ना

  1. <body> टैग के अंदर <h1> टैग का उपयोग करके मुख्य हेडिंग लिखें।
  2. <p> (Paragraph) टैग का उपयोग करके कुछ टेक्स्ट लिखें।
  3. पेज को सुंदर बनाने के लिए <style> टैग (Internal CSS) का उपयोग करके बैकग्राउंड कलर और फॉन्ट कलर सेट करें।
  4. फाइल को सेव करें और ब्राउज़र में खोलकर परिणाम देखें।
<!DOCTYPE html>
<html>
<head>
    <title>My First Web Page</title>
    <style>
        body { background-color: #f0f8ff; font-family: Arial; }
        h1 { color: #ff4500; text-align: center; }
        p { color: #333; font-size: 18px; text-align: center; }
    </style>
</head>
<body>
    <h1>Welcome to Web Designing</h1>
    <p>This is my first HTML and CSS page.</p>
</body>
</html>
चित्र 19.1: HTML/CSS कोड और ब्राउज़र में उसका आउटपुट (Output)

3. परिणाम (Result)

HTML के बेसिक टैग्स (h1, p) और CSS (color, background, font) का उपयोग करके सफलतापूर्वक एक साधारण वेब पेज बनाया गया।
