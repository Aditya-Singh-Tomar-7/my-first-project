2. कार्यविधि (Procedure)

Python एक बहुत ही आसान और लोकप्रिय प्रोग्रामिंग भाषा है।

A. IDLE खोलना और स्क्रिप्ट लिखना

  1. Start Menu में Python IDLE सर्च करें और इसे ओपन करें। यह Python का शेल (Shell) खोल देगा।
  2. ऊपर मेन्यू में File ➔ New File (Ctrl + N) पर क्लिक करें। इससे एक खाली कोडिंग स्क्रीन खुल जाएगी।

B. कोडिंग करना (Writing the Code)

  1. कोडिंग स्क्रीन में स्क्रीन पर टेक्स्ट प्रिंट करने के लिए print() फंक्शन का उपयोग करें।
    print("Hello World!")
  2. वेरिएबल (Variable) मेमोरी में एक बॉक्स की तरह होता है जो डेटा स्टोर करता है। x नाम का एक वेरिएबल बनाएं:
    x = 10
    y = 20
    print("X की वैल्यू है:", x)
    print("Y की वैल्यू है:", y)

C. प्रोग्राम को रन (Run) करना

  1. कोड लिखने के बाद File ➔ Save (Ctrl + S) पर क्लिक करें। फाइल को first_program.py नाम देकर सेव करें (Python फाइल का एक्सटेंशन .py होता है)।
  2. प्रोग्राम को चलाने के लिए मेन्यू में Run ➔ Run Module पर क्लिक करें, या कीबोर्ड से F5 बटन दबाएं।
  3. आउटपुट वापस Python Shell (पहली वाली स्क्रीन) पर दिखाई देगा।
# first_program.py (Script Window)
print("Hello World!")
x = 10
y = 20
print("X की वैल्यू है:", x)

3. परिणाम (Result)

Python IDLE का उपयोग करके सफलतापूर्वक पहला प्रोग्राम (.py फाइल) लिखा, सेव किया और F5 की (Key) दबाकर वेरिएबल्स का आउटपुट प्रिंट किया गया।
