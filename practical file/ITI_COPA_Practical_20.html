3CSS Layout ToolsFlexbox / Grid Layout

2. कार्यविधि (Procedure)

A. प्रोजेक्ट संरचना (Project Structure)

  1. अपने कंप्यूटर में अपनी 'Frontend-fundamentals' डायरेक्टरी के अंदर एक नया फोल्डर बनाएं। इस फोल्डर में index.html (स्ट्रक्चर के लिए) और style.css (डिजाइन के लिए) फाइलें बनाएं ताकि बाद में इस क्लोन को GitHub पर आसानी से अपलोड किया जा सके।
  2. HTML फाइल में <link rel="stylesheet" href="style.css"> का उपयोग करके CSS फाइल को कनेक्ट करें।

B. नेविगेशन बार (Navbar) बनाना

  1. HTML में <header> या <nav> टैग लें।
  2. इसमें Amazon का लोगो (Logo), एक सर्च बार (Search input box), और कार्ट (Cart) आइकॉन बनाएं।
  3. CSS में display: flex; का उपयोग करके इन सभी को एक सीध (Horizontal line) में व्यवस्थित करें और बैकग्राउंड कलर गहरा (Dark Blue/Black) सेट करें।

C. हीरो सेक्शन और प्रोडक्ट ग्रिड (Hero & Product Grid)

  1. नेविगेशन बार के ठीक नीचे एक बड़ा बैनर (Hero Image) लगाएं।
  2. उसके नीचे अलग-अलग प्रोडक्ट्स दिखाने के लिए HTML के <div class="box"> बनाएं।
  3. CSS में display: grid; का उपयोग करके इन्हें 3 या 4 कॉलम के बॉक्स लेआउट (Grid) में बदलें।

3. परिणाम (Result)

HTML के स्ट्रक्चर और CSS (Flexbox व Grid) लेआउट का उपयोग करके Amazon ई-कॉमर्स वेबसाइट का एक रिस्पॉन्सिव फ्रंटएंड (Frontend Clone) सफलतापूर्वक तैयार किया गया।
