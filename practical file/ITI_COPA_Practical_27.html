1कंप्यूटर सिस्टम (PC)विंडोज ऑपरेटिंग सिस्टम के साथ
2Windows Securityइन-बिल्ट एंटीवायरस (Windows Defender)

2. कार्यविधि (Procedure)

कंप्यूटर को वायरस (Virus) और मैलवेयर (Malware) से सुरक्षित रखने के लिए उसे स्कैन करना आवश्यक है। Windows 10/11 में इन-बिल्ट 'Windows Security' होती है:

  1. Start Menu पर क्लिक करें और Windows Security सर्च करके उसे ओपन करें।
  2. लेफ्ट मेन्यू में Virus & threat protection विकल्प पर क्लिक करें।
  3. यहां आपको 'Quick scan' का बटन दिखाई देगा। इस पर क्लिक करें।
  4. सिस्टम स्कैन शुरू कर देगा। इसमें कुछ मिनटों का समय लग सकता है।
  5. यदि आप पूरा कंप्यूटर गहराई से स्कैन करना चाहते हैं, तो 'Scan options' पर क्लिक करें और 'Full scan' को चुनकर 'Scan now' पर क्लिक करें।
  6. स्कैन पूरा होने के बाद, यदि कोई वायरस मिलता है, तो उसे 'Quarantine' या 'Remove' करने का विकल्प आएगा, जिसे सेलेक्ट करके सिस्टम को सुरक्षित करें।
