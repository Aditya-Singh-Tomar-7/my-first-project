उद्देश्य: JavaScript और DOM की मदद से बटन (Button) क्लिक पर HTML टेक्स्ट बदलना।

क्र.सं.सॉफ्टवेयर / उपकरणविवरण
1Text EditorVS Code (कोडिंग के लिए)
2Web BrowserChrome / Edge

2. कार्यविधि (Procedure)

Document Object Model (DOM) की मदद से JavaScript हमारे HTML पेज के किसी भी हिस्से को बदल सकती है।

  1. HTML एलिमेंट बनाना: <body> के अंदर एक हेडिंग बनाएं और उसे एक विशेष ID दें ताकि JS उसे पहचान सके।
    <h2 id="demo">Old Text</h2>
  2. बटन बनाना: एक बटन बनाएं और उसमें onclick एट्रिब्यूट (Attribute) लगाएं, जो बटन दबाने पर चलेगा।
    <button onclick="changeText()">Click Me</button>
  3. JavaScript फंक्शन लिखना: अब <script> टैग के अंदर changeText() नाम का फंक्शन बनाएं।
    function changeText() {
        document.getElementById("demo").innerHTML = "New Text Successfully Changed!";
    }
  4. आउटपुट: पेज रिफ्रेश करें। जैसे ही आप "Click Me" बटन पर क्लिक करेंगे, हेडिंग "Old Text" से बदलकर "New Text Successfully Changed!" हो जाएगी।
चित्र 22.1: DOM की मदद से बटन क्लिक करने पर HTML कंटेंट का बदलना

3. परिणाम (Result)

JavaScript और Document Object Model (DOM) के getElementById और innerHTML प्रॉपर्टी का उपयोग करके बटन क्लिक इवेंट (Event) पर सफलतापूर्वक HTML टेक्स्ट बदला गया।
