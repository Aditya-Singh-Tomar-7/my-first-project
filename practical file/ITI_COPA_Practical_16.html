प्रयोग संख्या - 16 (Practical No. 16)

उद्देश्य: CMD से IP एड्रेस और नेटवर्क कनेक्टिविटी (Ping) चेक करना।

1. आवश्यक उपकरण (Tools Required)

क्र.सं.सॉफ्टवेयर / उपकरणविवरण
1कंप्यूटर (PC)विंडोज ऑपरेटिंग सिस्टम के साथ
2Command Prompt (CMD)विंडोज का इन-बिल्ट टूल
3इंटरनेट या LAN कनेक्शननेटवर्क चेक करने के लिए

2. कार्यविधि (Procedure)

सबसे पहले कीबोर्ड से Win + R दबाएं, cmd टाइप करें और Enter दबाकर Command Prompt खोलें।

A. कंप्यूटर का IP एड्रेस पता करना (Checking IP Address)

  1. कमांड प्रॉम्प्ट (CMD) में टाइप करें: ipconfig और Enter दबाएं।
  2. स्क्रीन पर नेटवर्क की जानकारी आ जाएगी। इसमें IPv4 Address के सामने लिखा हुआ नंबर आपके कंप्यूटर का IP एड्रेस होगा (जैसे- 192.168.1.15)।

B. नेटवर्क कनेक्टिविटी (Ping) चेक करना

Ping कमांड का उपयोग यह जांचने के लिए किया जाता है कि आपका कंप्यूटर इंटरनेट या नेटवर्क के किसी दूसरे डिवाइस से जुड़ा है या नहीं।

  1. इंटरनेट चालू है या नहीं, यह चेक करने के लिए टाइप करें: ping google.com और Enter दबाएं।
  2. यदि 'Reply from...' लिखकर आ रहा है, तो इसका मतलब इंटरनेट सही से काम कर रहा है।
  3. यदि 'Request timed out' या 'Destination host unreachable' आता है, तो कनेक्शन में समस्या है।

3. परिणाम (Result)

Command Prompt (CMD) के माध्यम से ipconfig कमांड चलाकर सिस्टम का IP Address (IPv4) पता किया गया और Ping कमांड चलाकर इंटरनेट नेटवर्क कनेक्टिविटी का सफलतापूर्वक परीक्षण किया गया।
