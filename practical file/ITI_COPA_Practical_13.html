प्रयोग संख्या - 13 (Practical No. 13)

उद्देश्य: MySQL में डेटाबेस (Database) और टेबल (Table) बनाकर उसमें डेटा इन्सर्ट (Insert) करना।

1. आवश्यक उपकरण एवं सॉफ्टवेयर

क्र.सं.सॉफ्टवेयर / उपकरणविवरण
1कंप्यूटर सिस्टम (PC)Windows OS के साथ
2XAMPP Server / MySQL Serverडेटाबेस मैनेजमेंट सिस्टम (DBMS)

2. कार्यविधि (Procedure)

इस प्रैक्टिकल में हम SQL (Structured Query Language) कमांड्स का उपयोग करेंगे:

  1. MySQL खोलना: XAMPP कण्ट्रोल पैनल से MySQL स्टार्ट करें और 'Shell' या कमांड प्रॉम्प्ट खोलकर MySQL में लॉग इन करें।
    mysql -u root -p
  2. नया डेटाबेस बनाना: 'Aditya' नाम का एक नया डेटाबेस बनाने के लिए निम्न कमांड टाइप करें:
    CREATE DATABASE Aditya;
  3. डेटाबेस का चयन करना: इस डेटाबेस के अंदर काम करने के लिए इसे सेलेक्ट करें:
    USE Aditya;
  4. टेबल बनाना (Create Table): अब 'students' नाम की एक टेबल बनाएं जिसमें 'id' और 'name' कॉलम हों:
    CREATE TABLE students (
      id INT PRIMARY KEY,
      name VARCHAR(50)
    );
  5. डेटा डालना (Insert Data): इस टेबल में छात्रों का रिकॉर्ड जोड़ने के लिए INSERT कमांड का प्रयोग करें:
    INSERT INTO students (id, name) VALUES (1, 'Rahul');
    INSERT INTO students (id, name) VALUES (2, 'Sumit');
  6. डेटा देखना (Select Data): भरे हुए डेटा को देखने के लिए:
    SELECT * FROM students;

3. परिणाम (Result)

MySQL डेटाबेस मैनेजमेंट सिस्टम में सफलतापूर्वक 'Aditya' नाम का डेटाबेस बनाया गया, उसमें टेबल बनाई गई और SQL कमांड्स की मदद से डेटा इन्सर्ट किया गया।
