प्रयोग संख्या - 07 (Practical No. 07)

उद्देश्य: MS Word में नया डॉक्यूमेंट बनाना, उसे सेव करना और टेक्स्ट फॉर्मेटिंग (Text Formatting) का अभ्यास करना।

1. आवश्यक उपकरण एवं सॉफ्टवेयर (Tools & Software Required)

क्र.सं. सॉफ्टवेयर / उपकरण का नाम विवरण
1 कंप्यूटर सिस्टम (Desktop/Laptop) इनपुट डिवाइस (कीबोर्ड, माउस) के साथ
2 एप्लीकेशन सॉफ्टवेयर Microsoft Word (MS Office Suite)

2. कार्यविधि (Procedure)

A. नया डॉक्यूमेंट बनाना और सेव करना (Create & Save Document)

  1. सबसे पहले Start Menu पर क्लिक करें और Word सर्च करके उसे ओपन करें।
  2. स्क्रीन पर Blank Document पर क्लिक करें, जिससे एक नया और खाली पेज खुल जाएगा।
  3. डॉक्यूमेंट को सुरक्षित करने के लिए File मेन्यू में जाकर Save As पर क्लिक करें (या शॉर्टकट Ctrl + S दबाएं)।
  4. अपनी फाइल की लोकेशन (जैसे Desktop या Documents) चुनें, फाइल का नाम टाइप करें और 'Save' बटन पर क्लिक करें।

B. टेक्स्ट फॉर्मेटिंग (Text Formatting Tools)

होम टैब (Home Tab) के 'Font' और 'Paragraph' ग्रुप में टेक्स्ट को आकर्षक बनाने के लिए कई टूल्स होते हैं। किसी भी टूल का उपयोग करने से पहले टेक्स्ट को सेलेक्ट (Select) करना आवश्यक है।

  1. Font Style और Size बदलना:
    • टेक्स्ट को सेलेक्ट करें और Font ड्रॉपडाउन (जैसे Calibri या Arial) से मनचाहा फॉन्ट चुनें।
    • Font Size बॉक्स (उदा. 11, 12, 14) से अक्षरों का आकार बढ़ाएं या घटाएं।
  2. Bold, Italic, Underline:
    • अक्षरों को मोटा (गहरा) करने के लिए B Ctrl + B पर क्लिक करें।
    • अक्षरों को तिरछा करने के लिए I Ctrl + I पर क्लिक करें।
    • अक्षरों के नीचे लाइन खींचने के लिए U Ctrl + U पर क्लिक करें।
  3. टेक्स्ट अलाइनमेंट (Text Alignment): पैराग्राफ ग्रुप में मौजूद अलाइनमेंट बटन्स का उपयोग करके टेक्स्ट की दिशा सेट करें:
    • Align Left Ctrl + L: टेक्स्ट को बायीं ओर रखना।
    • Center Ctrl + E: टेक्स्ट को बीच (मध्य) में रखना।
    • Align Right Ctrl + R: टेक्स्ट को दायीं ओर रखना।
    • Justify Ctrl + J: टेक्स्ट को दोनों किनारों (बायें और दायें) से बराबर करना।

3. सावधानियां (Precautions)

  • कंप्यूटर पर काम करते समय अपनी फाइल को बीच-बीच में Ctrl + S दबाकर सेव करते रहें ताकि बिजली जाने पर डेटा नष्ट न हो।
  • किसी भी टेक्स्ट पर फॉर्मेटिंग (Bold, Italic आदि) लागू करने से पहले माउस की मदद से उसे सेलेक्ट (Select) करना अनिवार्य है, अन्यथा फॉर्मेटिंग काम नहीं करेगी।

4. परिणाम (Result)

Microsoft Word में सफलतापूर्वक एक नया ब्लैंक डॉक्यूमेंट बनाया गया, उसे सेव किया गया, और 'Home' टैब के फॉन्ट तथा पैराग्राफ ग्रुप का उपयोग करके टेक्स्ट पर विभिन्न फॉर्मेटिंग लागू की गई।
