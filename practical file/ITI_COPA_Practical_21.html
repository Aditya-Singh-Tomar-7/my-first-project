2. कार्यविधि (Procedure)

JavaScript वेब पेज को इंटरैक्टिव (Interactive) बनाती है। HTML में JS कोड को <script> टैग के अंदर लिखा जाता है।

A. अलर्ट बॉक्स (Alert Box) बनाना

  1. एक नई HTML फाइल बनाएं और उसके <body> टैग के अंदर <script> टैग शुरू करें।
  2. स्क्रिप्ट के अंदर टाइप करें: alert("Welcome to JavaScript!");
  3. जैसे ही आप इस पेज को ब्राउज़र में खोलेंगे, स्क्रीन के ऊपर एक पॉप-अप बॉक्स (Alert) दिखाई देगा जिस पर यह मैसेज लिखा होगा।

B. कंसोल आउटपुट (Console Output) प्रिंट करना

  1. उसी <script> टैग के अंदर अगली लाइन में टाइप करें: console.log("This is a console message.");
  2. पेज को ब्राउज़र में रिफ्रेश करें।
  3. यह मैसेज स्क्रीन पर नहीं दिखेगा। इसे देखने के लिए कीबोर्ड से F12 (या Right Click ➔ Inspect) दबाकर ब्राउज़र का Developer Tools खोलें।
  4. वहाँ Console टैब पर क्लिक करें। आपका मैसेज वहां प्रिंट हुआ दिखाई देगा। डेवलपर्स इसका उपयोग गलतियां (Bugs) खोजने के लिए करते हैं।

3. परिणाम (Result)

JavaScript के alert() और console.log() फंक्शन का सफलतापूर्वक उपयोग करके वेब पेज पर पॉप-अप मैसेज और कंसोल आउटपुट प्रदर्शित किया गया।
